# Third-party notices

Original Waymark code is **MIT OR Apache-2.0**. Dependencies, bundled components, data and fonts retain their respective licenses; the root dual license does not replace them.

The [plain-text notice bundle](apps/web/public/third-party-notices.txt) is served by Next.js at **/third-party-notices.txt**. It contains exact available upstream copyright/license/notice texts for 86 installed package/version entries and 131 Next.js bundled-component notice files, plus the two Google Fonts OFL texts. It intentionally covers more than the browser payload. No runtime feature or UI route was added.

## Snapshot and method

Audited release candidate: `c48d23687d0951a1c41bf48a4415148da5c07f71` (2026-11-11). `pnpm licenses list --json` enumerated installed Windows dependencies. Top-level LICENSE/LICENCE/NOTICE/COPYING/COPYRIGHT/AUTHORS files were reproduced verbatim, with line endings normalized. Next.js `dist/compiled` license/notice files were also collected recursively. Registry-declared licenses were separately inspected for all **178** lockfile package/version entries, including optional platform variants: none was undeclared and none was AGPL/GPL-only. Registry labels alone do not prove binary/source compliance.

## Provenance boundaries and outstanding checks

- The [Learn handoff](docs/learning/learn-handoff.md#reference-research-no-copied-agpl-material) records learnharness as **architectural inspiration only**, with no source, prompt, schema, asset or dependency copied. No AGPL dependency was found. This inventory is not an exhaustive source-similarity proof.
- Curriculum prose remains **DRAFT**. Bibliographic references and taxonomy links are not a grant to copy source texts or a claim of editorial approval; preserve the restrictions in [curriculum sources](packages/learning/src/curriculum/sources.ts).
- **Before distributing a Linux image or native executable:** inspect the exact shipped sharp/libvips, Lightning CSS, PGlite/WASM and other bundled artifacts, retain their notices and verify corresponding-source/replacement obligations. Installed Windows notices plus registry metadata do not certify those other artifacts. No Docker image or binary download is authorized/published by this task.
- No complete native corresponding-source archive is supplied here. A platform-specific distribution must not claim compliance based solely on this file.
- Root `LICENSE-APACHE` contains a GraphRAG copyright attribution inconsistent with `LICENSE-MIT`; provenance/correction is separately tracked in [issue #147](https://github.com/Philipjj609/waymark/issues/147). This task changes no root license or copyright holder.
- Refresh this bundle when dependencies/assets change; package-manager metadata is an inventory aid, not a substitute for upstream notices and provenance review.
